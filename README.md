# മഷിത്തണ്ട് (Mashithandu)

> **GMHHS Punkunnam 1991 SSLC Batch (Class 10) — 10 Reunions & Memories Website**

A nostalgic, mobile-first digital sanctuary created for the 1991 Class 10 batch of Government Model Higher Secondary School, Punkunnam, Thrissur, Kerala.

## 🌟 Highlights
- **Kerala Botanical Slate Aesthetic**: Deep mashi green, kasavu gold, warm parchment, and chalkboard slate.
- **Interactive Magic Slate (മാന്ത്രിക സ്ലേറ്റും മഷിത്തണ്ടും)**: HTML5 chalkboard canvas that simulates erasing chalk with *Mashithandu* to reveal vintage class memories.
- **10 Reunions Timeline (2014–2024)**: Milestone cards covering all 10 gatherings with dates, venues, and 1-tap gallery filtering.
- **50+ Photo Gallery**: Filterable by reunions, vintage school days (1991), teachers, campus, and candid moments with touch-swipe lightbox and live search.
- **Then & Now (1991 vs 2024)**: Interactive split slider comparing teenage school uniforms with reunion smiles.
- **Teachers Tribute (ഗുരുവന്ദനം)**: Revered teachers of 1991 with quotes and tributes.
- **Memory Wall (സ്മൃതിത്താളുകൾ)**: Interactive guestbook with persistent local storage.
- **ഓർമ്മ ഈണം**: Zero-dependency Web Audio school bell and pentatonic flute synthesizer.
- **WhatsApp Sharing**: 1-click sharing pre-formatted for WhatsApp batch groups.

## 🚀 Hosting Instructions
This is a 100% static, zero-dependency site. You can host it immediately on:

### Option 1: GitHub Pages (Recommended - 1 Click)
1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Source**, select `Deploy from a branch`.
3. Choose branch `main` and folder `/ (root)`, then click **Save**.
4. Your site will be live at: `https://dhananjayn875.github.io/mashithandu/`

### Option 2: Vercel / Netlify / Cloudflare Pages
- Connect this GitHub repo and click Deploy (no build command needed, publish directory is `.`).

### Option 3: Run Locally
```bash
python3 -m http.server 8080
# Open http://localhost:8080 in your browser
```
